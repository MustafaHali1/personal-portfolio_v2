# Mustafa Hali — Yeni Nesil Portfolyo & Supabase Dashboard

Bu proje, Mustafa Hali için insansı, karakterli ve hikaye odaklı olarak sıfırdan inşa edilmiş yeni nesil kişisel portfolyo ve dinamik yönetim paneli (Dashboard) uygulamasıdır.

## 🚀 Öne Çıkan Özellikler
- **İnsansı Hikaye Anlatımı:** Robotik PR jargonu yerine gerçek bir Bilgisayar Mühendisliği öğrencisinin serüveni (C/C++ algoritmaları, Kotlin/Android ve Yapay Zeka entegrasyonları).
- **İnteraktif Android Simülatörü:** Ekranda yer alan gerçekçi Android kasası ve tıklanabilir uygulamalar (Kutlama sitesi, geliştirici günlüğü, araçlar, iletişim).
- **Projelerin Arkasındaki Motivasyon:** Her projenin "Neden Yaptım?" hikayesi, görseli ve canlı linkleri.
- **Canlı Geliştirici Durumu ("Şu An"):** Çalan müzik, kahve kupası sayısı, üzerinde çalışılan konu ve kampüs lokasyonu.
- **Kapsamlı Dashboard (`/admin`):** Sitedeki tüm profil, proje, not ve durumları kodlara girmeden tek panelden düzenleme.
- **Supabase PostgreSQL Entegrasyonu:** `@supabase/supabase-js` ile bulut senkronizasyonu + SQL şeması + yerel önbellek + tek tıkla JSON yedekleme.

## 🛠️ Kurulum & Çalıştırma
```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Üretim derlemesi
npm run build
```
